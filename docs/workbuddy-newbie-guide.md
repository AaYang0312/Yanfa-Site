# WorkBuddy 连接元发官网管理 MCP · 新手教程

写给第一次使用 WorkBuddy 的你。照着做，大约 10 分钟就能让 WorkBuddy 帮你查询和准备产品修改。

**先记住最重要的一条规则：**

> WorkBuddy 保存的只是「草稿」，官网不会因为 AI 改了就变。
> 每次改完，都需要管理员打开它给的链接，核对后点一下「保存并更新官网」，官网才会更新。
> 这是故意设计的安全机制：AI 准备，人来把关。

---

## 一、它能帮我做什么？

WorkBuddy 连上后可以（共 11 个工具）：

| 类别 | 能做的事 | 需要的权限 |
| --- | --- | --- |
| 查询 | 搜索产品、看产品全部资料（含图片数量、标签、版本号） | 只读查询 |
| 查图片 | 列出图片素材库：文件名、尺寸、格式、大小、指纹 | 只读查询 |
| 改产品 | 改文字资料、改图片标签/描述/顺序/封面、新建产品草稿 | 查询与编辑产品 |
| 发起发布 | 创建发布候选、创建发布意图（旧版兼容，一般不用） | 需要额外授权，不推荐新手开启 |
| 上传图片 | ❌ AI 不能上传新图。它只能给你打开上传页面的链接，图片由人在浏览器上传 | — |

## 二、开始前的准备

1. 一台装好 **WorkBuddy** 的电脑。
2. **官网管理员账号**（用户名 + 密码）。
3. 网络入口（二选一）：

| 入口 | 地址 | 说明 |
| --- | --- | --- |
| **推荐：Tailscale** | `https://yanfa.tail547bb.ts.net:9443` | 证书正常，无任何警告；电脑需安装 Tailscale 并登录同一网络 |
| 备用：公网临时入口 | `https://111.228.57.17:9444` | 自签证书。浏览器打开后台会提示「不安全」，点「高级 → 继续访问」即可；**如果 WorkBuddy 报证书/连接错误，就换 Tailscale 入口** |

下文以 Tailscale 地址为例。如果你用公网入口，把地址换掉即可，步骤完全一样。

## 三、第一步：创建连接密钥（Token）

1. 浏览器打开后台设置页：
   `https://yanfa.tail547bb.ts.net:9443/admin/settings/`
2. 用管理员账号登录。
3. 在「**连接 WorkBuddy**」面板填写：
   - **连接名称**：比如 `产品资料维护`（方便以后认出它）；
   - **失效时间**：默认是 30 天后，可自行调整（到期后 WorkBuddy 会连不上，需要重新创建）；
   - **允许的操作**：
     - 只想让 AI 查资料 → 选「**只读查询**」；
     - 想让 AI 帮你改产品 → 选「**查询与编辑产品**」。
4. 点「**创建连接**」。
5. 页面会显示一串以 `t_` 开头的**连接密钥**——**只显示这一次**！
   点「复制密钥」，先贴到记事本临时保存，再点「已保存，隐藏密钥」。
6. ⚠️ 密钥等于后台的一把钥匙：**不要发到微信/聊天窗口/截图里**。泄露了就回这个页面点「撤销连接」，再重新创建一个。

> 已经创建过的连接会列在同一页面下方，随时可以「撤销连接」。

---

## 四、第二步：在 WorkBuddy 里添加 MCP 服务

设置页其实已经把配置模板准备好了（「在 WorkBuddy 中添加连接」区域，点「复制连接配置」即可）。手动写的话长这样：

```json
{
  "mcpServers": {
    "yuanfa-catalog": {
      "type": "streamableHttp",
      "url": "https://yanfa.tail547bb.ts.net:9443/mcp",
      "headers": {
        "Authorization": "Bearer t_把这里替换成你的密钥"
      }
    }
  }
}
```

操作步骤：

1. 打开 WorkBuddy 的设置，找到 **MCP / 自定义工具 / 连接** 之类的入口（不同版本叫法略有差异）。
2. 选择添加 **HTTP 类型（streamableHttp）** 的 MCP 连接。
3. 把上面的 JSON 填进去（或直接粘贴设置页复制的模板），注意两处：
   - `url` **结尾的 `/mcp` 不能少**；
   - `Bearer ` 后面换成你自己的密钥（Bearer 和密钥之间有一个空格）。
4. 保存配置，重启或刷新 WorkBuddy（按它的提示）。

---

## 五、第三步：验证连接成功

对 WorkBuddy 说下面任意一句：

> 列出你现在可用的工具

应该能看到 11 个工具：`search_products`、`get_product`、`update_product`、`create_product`、`delete_draft`、`list_media`、`open_upload`、`create_candidate`、`get_candidate`、`request_publication`、`get_publication`。

再试一句：

> 帮我搜索产品 F30A

能返回产品资料，就说明整条链路通了。

## 六、日常怎么用？直接说人话就行

**查资料：**
- 「搜索所有码钉枪，列出型号和简介」
- 「打开 BW120G，告诉我它的简介、应用场景，以及一共有几张图」
- 「列出 BW120G 每张图片的文件名、尺寸和格式」——AI 会自动查图片素材库来核对

**改产品（改完只是草稿）：**
- 「把 F30A 的简介改成"……"，其他内容保持不变，保存为草稿」
- 「把 BW120G 第二张图片的标签改成"整机侧面"，描述改成"……"，其他不动」
  —— 负责任的 AI 会先核对原图信息再改，你可以提醒它：「改之前先核对现有图片」
- 「把 BW120G 的封面图换成现在图片列表里的第二张」
- 「新建一个产品：名称……，分类……」（会建成**下架状态的草稿**，不影响官网）

**改完之后，WorkBuddy 会给你一个链接**，形如：
`https://…/admin/products/edit/?id=…`

**最后一步必须由人完成：**
1. 用管理员账号打开这个链接；
2. 核对文字、图片、上下架状态；
3. 点「**保存并更新官网**」；
4. 等页面显示「官网已更新」。
   想反悔？不点这个按钮就是不上线；从未发布过的草稿也可以让 WorkBuddy 用 `delete_draft` 删掉。

## 七、常见问题对照表

| 现象 / 报错 | 原因 | 怎么办 |
| --- | --- | --- |
| 提示 401 / UNAUTHENTICATED | 密钥填错、已过期或已撤销 | 回设置页重新创建连接，更新 WorkBuddy 配置 |
| 提示 403 / FORBIDDEN | 密钥权限不够（比如只给了只读却让它改产品） | 撤销旧连接，新建一个勾选「查询与编辑产品」的连接 |
| 提示 VERSION_CONFLICT（或 409/412） | 别人（或另一个标签页）刚改过这个产品 | 让 WorkBuddy「重新读取该产品后，基于最新版本再改一次」 |
| WorkBuddy 连不上 / 证书错误（公网入口） | 自签证书被客户端拒绝 | 换 Tailscale 入口的地址 |
| 看不到工具列表 | `url` 少了 `/mcp`，或类型没选 streamableHttp | 检查配置 JSON |
| 改了但官网没变化 | **正常！** 草稿还需要人确认 | 打开产品编辑链接，点「保存并更新官网」 |
| 密钥忘了 / 没保存 | 密钥只显示一次，无法找回 | 撤销旧连接，重新创建 |

## 八、安全守则（请务必遵守）

1. **密钥不进聊天**：不要把密钥发给任何人、贴进对话、截进截图。
2. **权限最小化**：只是查资料就用「只读查询」；需要改再开编辑。
3. **定期轮换**：失效时间别设太长；人员变动或怀疑泄露时立即「撤销连接」。
4. **发布永远人把关**：这是这套系统的底线设计——AI 只能准备草稿，官网更新必须由管理员在后台确认。
